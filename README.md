Project Title : FinSight

Project Description:

FinSight is a web-based personal finance management application designed to help users track and understand their spending habits. Users can create an account, securely log in, record their expenses, and view their spending through a dashboard. The application also provides intelligent insights from expense data to help users better understand their financial behavior.

Features:

1.User Authentication

•	User signup and login
 
•	Secure password hashing
 
•	Session-based authentication

2.Expense Tracking

•	Add and store expenses
 
•	Categorize expenses
 
•	Track expenses by date
 
•	View personal expense history

3.Expense Analysis

•	Monthly expense tracking
 
•	Dashboard-based spending overview

4.Machine Learning Insights

•	Expense prediction
 
•	Spending behavior classification
 
•	Unusual spending detection

5.Cloud Database

•	MongoDB Atlas for storing user and expense data

Technologies Used :

Frontend : HTML, CSS, JavaScript

Backend : Python, Flask

Database : MongoDB Atlas

Machine Learning : NumPy, Pandas, Scikit-learn, SciPy, Joblib

Authentication : bcrypt, Flask Sessions
